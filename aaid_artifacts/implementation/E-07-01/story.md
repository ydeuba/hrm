## User Story

**As a** Management
**I want** to print or save the dashboard as a PDF
**so that** I can circulate it in meetings

## Acceptance Criteria

- [x] AC-1: Given "Export / Print", then `/print/dashboard?<current filters>` opens, the browser print dialog is triggered, and navigation and filters are hidden.
- [x] AC-2: Given A4 portrait or landscape, then no panel or chart splits across pages, and every page has a header (filters, range, generated time) and the footer "Cloudtech Services · Confidential".
- [x] AC-3: Given grayscale printing, then bands remain distinguishable by their text labels.
