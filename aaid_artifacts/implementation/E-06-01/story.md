## User Story

**As a** Management
**I want** an engineer's sprint-by-sprint trend against the org average
**so that** I can prepare for their appraisal conversation

## Acceptance Criteria

- [x] AC-1: Given a row click, then a modal shows name, designation, team, "overall rank X of N", designation rank, average, total, sprints, rating, last 3, momentum, best/worst, variability and RUN count.
- [x] AC-2: Given the chart, then the engineer line has gaps for RUN and N/A, and a dashed org-average line is shown.
- [x] AC-3: The modal traps focus, closes on Esc or the close button, and returns focus to the originating row.
