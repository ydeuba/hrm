## User Story

**As a** HR Admin
**I want** a searchable employee list
**so that** I can see who is tracked and find a record quickly

## Acceptance Criteria

- [x] AC-1: Given `/employees`, then I see name, code, team, designation, status and sprints scored.
- [x] AC-2: Given search text and team, designation or status filters, then the list narrows accordingly.
- [x] AC-3: Given more than 200 rows, then the list paginates with a cursor.
